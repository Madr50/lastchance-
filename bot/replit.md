# Twitter X Shop Bot

بوت تيليغرام لبيع حسابات تويتر X قديمة الإنشاء.

## المتطلبات
- Python 3.10+
- المتغيرات البيئية في `.env` (انظر `.env.example`)

## التشغيل
```bash
pip install -r requirements.txt
python main.py
```

## المتغيرات البيئية
| المتغير | الوصف |
|---------|-------|
| BOT_TOKEN | توكن البوت من @BotFather |
| BOT_USERNAME | اسم البوت بدون @ |
| ADMIN_ID | معرف الأدمن الرقمي |
| ADMIN_USERNAME | اسم المستخدم للأدمن |
| ADMIN_PASSWORD | كلمة مرور لوحة التحكم |
| SHOP_NAME | اسم المتجر |
| USDT_ADDRESS | عنوان محفظة USDT TRC20 |
| SESSION_SECRET | مفتاح الجلسة (عشوائي) |
| WEBAPP_URL | رابط الميني آب (اختياري) |

## الميزات
- ✅ بيع حسابات تويتر مع صور ووصف
- ⭐ الدفع بنجوم تيليغرام
- 💎 الدفع بـ USDT TRC20
- 🎁 نظام دعوات مع رابط خاص لكل مستخدم
- 🏆 نظام مسابقات مع متابعة التقدم
- 🖥️ لوحة تحكم ويب للأدمن
- 📱 ميني آب للمتجر

## نظام المسابقات
- الأدمن ينشئ مسابقة بعنوان وصورة وعدد دعوات
- كل مستخدم يحصل على رابط دعوة خاص بالمسابقة
- يُحسب كل شخص يدخل البوت عبر الرابط
- عند الوصول للهدف يُعلن الفائز تلقائياً
